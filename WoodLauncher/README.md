# WoodLauncher

WoodLauncher is the Windows boot launcher and updater for the Wood product. The runtime that runs in TUNG is maintained in runtime-source/ and is installed by the separate WoodSetup build. The runtime-source subfolder is its own Git checkout for the source-only GitHub repository.

Build this component with build.bat. Output is release/WoodLauncher.exe. For complete versioning, staging, website publishing, and GitHub instructions, see ../DEVELOPMENT.md.
